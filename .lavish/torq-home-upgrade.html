Home upgrade — what replaces calories?

Agreed: "burnt kcal vs a kcal goal" is a diet-app metric in a strength app — it's estimated, it's noisy, and it doesn't tell you whether you're getting stronger. Three replacements below, each mocked as the real Home (hero and recents stay; only the goal block changes). All three use data the app already computes — nothing fake.

My take

C (Rank momentum) is the one that makes torq feel like torq — the rank system is the product's whole bet, and Home is where it should live. Pair it with A's week strip in the same block (strip on top, rank below — both are thin) and you replace calories with consistency + status in one move. B's load number is honest but is already half-covered by the volume sparkline lower on the page.
